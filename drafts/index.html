Главная — три варианта

Первый экран у всех трёх — без фотографии, только слова. Слова те же, что на текущей главной. Список «что я делаю / ещё я» расширяется одной строкой. Каждый вариант — EN/RU, светлая и тёмная тема, без внешних запросов.

  1. A

    Крупная типографика

    Имя и высказывание во весь первый экран, список — ниже строками с маленькими картинками.

  2. B

    Письмо

    Короткий абзац от первого лица вместо шапки, дальше список карточками с картинками.

  3. C

    Указатель

    Одна колонка, оглавление как в книге: маленькие картинки слева, строка на каждый проект.
